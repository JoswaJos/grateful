# Grateful 🙏

A gratitude journal app. Write down what you're grateful for each day, look back on past entries, and get gentle AI reflections on them.

## Tech stack

- **[Expo](https://expo.dev)** (React Native, Expo Router): cross-platform mobile app
- **[Clerk](https://clerk.com)**: sign-in and user accounts
- **[Supabase](https://supabase.com)**: Postgres database for journal entries
- **[Gemini](https://ai.google.dev)**: AI reflections and prompts

## How to run

```bash
npm install
npm run start:tunnel
```

Then scan the QR code with the Expo Go app on your phone.
